# Food Delivery Website UI

A responsive food delivery website interface built using HTML, CSS, and JavaScript. This project focuses on creating a modern and user-friendly food ordering experience for frontend development practice.

## Features

- Responsive navigation bar
- Food categories and restaurant sections
- Search functionality
- Restaurant and food item cards
- Promotional sections
- Responsive layout
- Clean and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

This project was created as a frontend development practice project to improve skills in HTML, CSS, JavaScript, responsive web design, DOM manipulation, and interactive user interfaces.
